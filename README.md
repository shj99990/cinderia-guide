## v2.3 UI 변경 (2026-11-20)

첫 화면에서는 **카드 설명**만 표시하고, 주요 작업을 3개 탭으로 분리했다.

1. **카드 설명** (기본): 캐릭터·계열·카드 종류 필터, 이름/효과 검색, 566개 카드 원문 설명 및 선행·후속 관계. 기존 인라인 검증 안내를 기본 카드 목록에서 제거
2. **코드 검증**: 탭 안에서 캐릭터 선택 및 검색 가능. 이전 48개 검증 기록과 37개 메커니즘 메모 대상의 합집합 **64개 카드**를 분류. 원본 코드/수정 모드/로그/미확인을 카드 상세에서 확인
