## v2.3.3 루 은신 해제 공격/후방 공격 분리 (2026-11-21)

- 루 카드의 번역상 동일한 '기습 공격'을 **破隐一击(은신 해제 공격)**과 **背刺(후방 공격)**으로 구분했다. 전자는 은신 후 시작한 유효 적중·능동 스킬 해제 조건, 후자는 실제 후방 적중 또는 확정 후방 효과다. 두 판정의 계산과 전용 카드 효과는 서로 다르다.
- 공개 카드 566개 원문 ID/한국어 이름/설명/강화 선택지/획득 선행·배타 데이터는 **그대로 보존**했다. 루 **16개 카드**에 별도 판정 라벨과 검증 메모를 추가하고 카드 목록·상세·코드 검증 탭에서 확인하도록 했다. 메커니즘 메모가 등록된 카드 수는 **37→50개**로 증가했다.
- 후방: 혼신의 일격, 순섬, 황폐, 급소 연속찌르기 4강. 은신 해제: 인내, 목 베기, 장막과 은신 해제 후속 카드. 은신 진입 수단 및 이름만 '기습'인 그림자 기습은 분리해 표시한다.
- 순섬 허공 콤보→충전→방향 전환, 은신과 후방 판정의 실전 동시 적용, 차크람 생성 시각은 **추정/미검증**으로 표시했다. 원본 코드·데이터, 수정 모드, 실측을 혼동하지 않는다.
- 근거별 상세 기록: [루 은신 해제 공격·후방 공격 분리](docs/RED-STEALTH-BACKSTAB-20261121-KO.md). 비공개 Drive findings는 **읽기 전용 미러**로 유지하며 GitHub에 원본 디컴파일 소스를 게시하지 않는다.
- 커넥터 파일 재조회로 원본 카드 566개/고유 UID 566개/역할 16개/메커니즘 메모 50개를 확인했다. **브라우저 실제 렌더링·모바일 조작·GitHub Pages 반영 시각은 아직 직접 확인하지 않았다**.

## v2.3 UI 변경 (2026-11-20)

첫 화면에서는 **카드 설명**만 표시하고, 주요 작업을 3개 탭으로 분리했다.

1. **카드 설명** (기본): 캐릭터·계열·카드 종류 필터, 이름/효과 검색, 566개 카드 원문 설명 및 선행·후속 관계. 기존 인라인 검증 안내를 기본 카드 목록에서 제거
2. **코드 검증**: 탭 안에서 캐릭터 선택 및 검색 가능. 이전 48개 검증 기록과 37개 메커니즘 메모 대상의 합집합 **64개 카드**를 분류. 원본 코드/수정 모드/로그/미확인을 카드 상세에서 확인
3. **빌드 엔진**: 탭 안에서 캐릭터별 엔진 선택. 기존 8개 경로와 데이터상 선행조건을 유지. 미등록 캐릭터는 빈 상태 안내

검증 자료가 있는 카드의 설명 창에서 **'이 카드의 코드 검증 보기'**를 누르면 해당 캐릭터의 코드 검증 탭으로 이동한다. 기존 필터/검색/팝업 연결 및 모바일 대응 구조를 보존하는 범위에서 UI를 정리했다.
