1. v2.1에서 수정한 관계 정보를 566개 카드에 유지한다. `groups/preconditions/mutex`는 원본 데이터에서 분리하고 `☆` AND와 일반 OR 조건을 구분한다.
2. v1.3의 코드 검증 **48개 항목**과 우마 카드 등급 **125개**를 다시 내장한다. 기존 '검증 기록만' 필터와 상세 정보·기술 ID 보기 및 검색을 유지한다.
